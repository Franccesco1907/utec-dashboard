# UTEC Dashboard

Dashboard de indicadores con Angular 13 y Chart.js. Instalación: `npm install`; desarrollo: `npm start` en http://localhost:4200.
Compilación: `npm run build:prod`; salida: `dist/indicadores`.
`npm test -- --watch=false --browsers=ChromeHeadless` requiere Chrome; el repositorio no contiene archivos `.spec.ts` ni un runner e2e.
No hay workflow de CI configurado.
